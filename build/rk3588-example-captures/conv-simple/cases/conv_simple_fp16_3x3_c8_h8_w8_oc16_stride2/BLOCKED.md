No source path encodes a convolution stride.  The FP16 shape parser accepts an sN field (expt/conv_simple.py:228-238), but _conv_params ignores it (lines 297-311) and make_regs always writes CNA_CONV_CON3 = (1<<3)|1 = 0x9, i.e. stride 1 (expt/conv_simple.py:408).  kernel_6_18/simple_conv.py hardcodes the same value at line 557.  Emitting a stride-2 case would require a new CNA_CONV_CON3 encoding that these sources do not provide.
