The grouped path cannot be expressed safely from these sources.  The FP16 make_regs() has no group-count register and its known-supported table has no grouped entry (expt/conv_simple.py:207-217,383-440).  The only grouped implementation is kernel_6_18/simple_conv.py::run_conv2d_grouped (lines 729-759), which slices input/weight/bias and calls run_conv2d_shape once per group; each call overwrites the shared BOs in write_buffers (lines 675-691) and does its own npu_submit (lines 871-872).  A single bundle would therefore need per-group BOs plus a multi-task PC chain, and the chain's PC_BASE_ADDRESS would have to be regcmd_addr + task_offset.  The bundle patch schema can only bind named buffer addresses, not the regcmd self-address, so the chain cannot be encoded without leaving an unpatched address.
