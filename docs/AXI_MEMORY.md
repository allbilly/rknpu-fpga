# Halfword memory to YPCB-shaped AXI

`rtl/rk_axi_mem.sv` connects the unchanged `rk_ew_dma` halfword memory port to
a single-outstanding AXI4 master. It does not replace the final command encoder,
decode tensor operations, convert numerical formats, or perform CPU layout
fixups. The arithmetic and command decoder are unchanged.

## Source evidence and limits

The local YPCB systest project at
`/home/fedora/ypcb/ref/ypcb_00338_1p1_hack`, revision
`8b13ecf71b7061dd43a2b1580f0caa469f64303f`, contains the generated configuration
`examples/YPCB_00338_1P1_systest/YPCB_00338_1P1_systest.gen/sources_1/bd/top/ip/top_mig_7series_0_0_1/top_mig_7series_0_0/mig.prj`.
Its SHA256 is
`adc1bcdb20b7aabb51f9359bf46eaea3c6e592819a9d88411ebf90e61e974d00`.
Lines 215–221 configure controller 0 for AXI, 31-bit addresses, 512-bit data,
4-bit IDs and **no narrow bursts**. Controller 1 repeats these settings.
This differs from the 128-bit XDMA-facing interface in the same project.

The same configuration enables ECC on a 72-bit physical DDR interface
(`mig.prj` lines 51–54). AMD's [UG586 AXI slave description](https://docs.amd.com/r/en-US/ug586_7Series_MIS/AXI4-Slave-Interface-Block)
states that masked AXI writes use read-modify-write inside an ECC-enabled MIG.
The adapter itself does not implement that operation. Before real integration,
establish initialized data/ECC for the complete allocated beats, verify masked
writes with the actual MIG configuration, and audit error reporting. The local
generated `example_design/rtl/example_top.v` combines the separate
`c0_app_ecc_multiple_err` and `c0_app_ecc_single_err` signals with its test error
status (line 664). This adapter handles AXI response errors only: it has no ECC
sideband input, and this audit does not establish that every ECC fault is
reflected in RRESP/BRESP. Do not discard the sidebands or claim complete DDR
error handling until their integration is specified and tested.

The adapter matches the MIG-side widths. It is not wired into that project's
interconnect, clock/reset logic or memory-controller IP. The existing `ypcb_top`
still uses the BRAM self-test. The source metadata is not proof of the actual
board's DDR population, calibration, routing or timing. No Xilinx IP is copied
or generated by this addition.

## Transfer contract

- Device addresses remain byte addresses. Bit 31 set or bit 0 set is an explicit
  local error, with no AXI transaction. There is no truncating address alias.
- Each accepted read issues one 64-byte-aligned, full-width AXI read beat:
  `ARADDR = address & ~63`, `ARLEN=0`, `ARSIZE=6`, `ARBURST=INCR`.
  The requested little-endian halfword is selected using address bits 5:1.
  Neighboring padding or guard bytes in that beat are physically read too,
  but are not issued as additional command words or interpreted by the decoder.
- Each write issues the corresponding aligned full-width beat with exactly
  the two requested `WSTRB` byte lanes enabled. Other data lanes are zero and
  disabled. There is no adapter read-modify-write or dependency on narrow transfers;
  an ECC-enabled MIG performs its own masked-write read-modify-write.
- ID is zero; lock, cache, protection and QoS fields are zero. `WLAST=1`.
  AW and W are held independently until their respective handshakes, in either
  order. A local write response is generated only after the B handshake.
- Only one local request is outstanding. Read and write requests are ordered;
  a subsequent request is refused until the prior local response is consumed.
  Local responses are registered and remain stable under backpressure.
- Any non-OKAY response, including EXOKAY for an unrequested exclusive operation,
  nonzero response ID, or missing `RLAST` produces a local error. Errors latch
  the adapter unavailable until reset; the DMA engine reports E5. Error read
  data is unspecified and must not be consumed numerically.

The adapter is for **ordinary, non-side-effecting RAM only**. A read fetches the
entire enclosing cache-line-sized beat; that whole 64-byte region must be mapped
and safe to read. Do not connect it to MMIO registers or an aperture whose
unrequested neighboring bytes have read side effects. The allowed numerical
halfword range is `0x00000000` through `0x7ffffffe`; downstream address decoding
must still enforce actual allocated/mapped memory. The last address reads the
beat at `0x7fffffc0`, without crossing the 2 GiB boundary. One aligned beat cannot
cross a 4 KiB AXI boundary.

No coherence or concurrent host access is provided. The eventual transport must
establish host-write visibility before starting DMA and device-write visibility
before reading outputs. B acknowledgment is the downstream AXI completion
contract, not a claim that a host CPU cache has been invalidated.

## Fault recovery and reset

The engine's existing memory timeout reports E8. The adapter deliberately does
not cancel asserted AW/W/AR channels when the engine times out: doing so after
a partial handshake can violate AXI and orphan a transaction. A pending write
may still modify RAM after an engine timeout. Neither errors nor reset roll
back writes. No further job may use those buffers until recovery completes.

Reset the engine, adapter **and affected downstream AXI transaction domain**
together, or first quiesce/drain that domain through a separately audited
transport. Resetting only this adapter while MIG/interconnect retains an old
response can misattribute that response to a later request. Missing RLAST is a
protocol fault, not a supported burst: the adapter returns an error and stops;
it does not attempt to salvage or drain malformed traffic. Joint reset is
required. This module is single-clock and supplies no CDC or calibration gate.

## Verification

`tests/tb_axi_mem.sv` uses an independent behavioral AXI RAM slave, randomized
channel stalls with seed `0x3588a512`, independent AW/W acceptance, delayed
responses, and byte-wise write strobes. Its directed tests cover all 32 lanes,
neighbor preservation, beat/4 KiB/2 GiB boundaries, invalid addresses, response
backpressure, both AW/W orders, delayed B, non-OKAY/ID/RLAST errors, sticky faults
and joint reset at six outstanding/response boundaries.

The same bench connects `rk_ew_dma` to the adapter and replays all nine unchanged
production command BO fixtures. It compares every halfword in the existing
full-memory check files and writes separate `axi_capture_*_observed.hex` files.
Six SUB(9) fault runs exercise R errors, dropped R, stalled AR, first B error,
dropped B and final B error. The latter must not report job completion and must
retain exactly one previously completed task.

`make test` runs these in Verilator and Icarus alongside all previous scenarios.
`make synth-check` additionally maps the standalone adapter to XC7 primitives.
Consult the source-bound reports for actual execution status. The behavioral
slave is not MIG simulation; standalone mapping is not an integrated DDR
netlist, physical timing, hardware validation or a complete FPGA runtime.

The `2434cc400305` evidence also includes a supplemental mapped-adapter run:
the same 16 tests execute with Yosys's `rk_axi_mem` netlist and the pinned Xilinx
functional primitive models, while DMA/core remain RTL. Its startup wrapper,
all commands and nine observed memory images are archived and fingerprinted in
`axi_mapped_report.json`. The clock is held for 200 ns before starting the
unchanged bench so the normal Xilinx global startup completes. This check is
separate from `make synth-check` and does not simulate MIG, ECC or routed delays.
